How payroll runs

Four steps, from the file to the bank.

Preparing the run, paying it, explaining it and settling at the end. Each one reads from HR and posts to the same ledger as finance.

01 · Pay run

Prepare the run

Basic, allowances, overtime and approved leave come from the employee file and attendance, so the run starts complete instead of from last month's spreadsheet.

See it in a demo

  1. 01Attendance locked

    Days worked and overtime closed for the month.

  2. 02Changes picked up

    Joiners, raises and leavers since the last run.

  3. 03Deductions applied

    Advances, loans and unpaid leave, set once.

  4. 04Variances shown

    Anyone whose pay moved more than 10%, with the reason.

02 · WPS

Approve and pay

Someone other than the preparer approves the run, then the WPS salary file goes to your bank or exchange house. Nobody is paid until everyone can be.

See it in a demo

  1. 01Bank details checked

    A missing IBAN holds the run, not just the person.

  2. 02Approved by a second person

    The preparer can never approve their own run.

  3. 03Salary file generated

    Employer and salary lines in the WPS format.

  4. 04Paid and confirmed

    The bank's confirmation is kept with the run.

03 · Payslips

Payslips and letters

Every employee gets a payslip that shows how their pay was worked out, and can open it again whenever a bank or landlord asks.

See it in a demo

  1. 01Issued from the run

    Sent the day the bank confirms.

  2. 02Every line explained

    Basic, allowances, overtime and deductions.

  3. 03Salary certificates

    Letters produced from the same figures.

  4. 04Kept on the file

    Every month, for as long as the law requires.

04 · End of service

Gratuity and final pay

End-of-service gratuity is accrued every month, so the final settlement is a number you already know, not a calculation started on someone's last day.

See it in a demo

  1. 01Accrued monthly

    21 days' basic a year for the first five years, 30 after.

  2. 02Posted to finance

    The provision grows in the ledger as it accrues.

  3. 03Final pay worked out

    Unused leave, notice and deductions on one sheet.

  4. 04Settled and closed

    Paid, signed for and kept on the file.

Controls and audit

No one pays a salary on their own.

The person who prepares the run never approves it. Bank details, salaries and the run itself each keep a full history.
