How HR runs

Four moments, kept in one employee file.

Hiring, documents, time off and the end of a contract. Each one writes to the same file that payroll, finance and operations read from.

01 · Hiring

Hire and onboard

From vacancy to first day. Applicants, interviews and the offer stay together, and a signed offer becomes the employee file without retyping.

    Headcount and budget agreed before the post goes up.

  4. 04First-day checklist

    Visa, laptop, access and induction, each with an owner.

02 · Documents

Keep documents current

Visas, Emirates IDs, passports and labour contracts live with the person. Every expiry date is watched, and the renewal starts while there is still time.

See it in a demo

  1. 01Stored on the file

    Scans kept with the issue and expiry dates.

  2. 02Reminders at 30, 14 and 3 days

    To the HR owner first, then their manager.

  3. 03Renewal opened

    A task with fees, appointments and a PRO owner.

  4. 04Closed with the new copy

    The fresh document replaces the old one on file.

03 · Time off

Time and leave

Check-ins, shifts and leave on one calendar. Balances update on approval, and payroll sees exactly the days it should pay.

See it in a demo

  1. 01Check-in recorded

    From the device, the app or the site.

  2. 02Leave requested

    With the balance and the team calendar beside it.

  3. 03Approved in one tap

    The manager sees who else is away first.

  4. 04Passed to payroll

    Unpaid days and overtime ready for the run.

04 · Reviews and exits

Reviews and exits

Probation reviews, appraisals and the last day follow a set path, so nothing about a person's time with you is left to memory.

See it in a demo

  1. 01Probation review

  2. 02Appraisal on record

    Goals, ratings and comments kept on the file.

  3. 03Notice and last day

    Checked against the contract's notice period.

  4. 04Clearance and settlement

    Assets returned, final pay sent to payroll.
